# DSH Shell — Android-оболочка для DeepSeek Harness Web GUI

Минимальное нативное Android-приложение (Kotlin + WebView), чтобы общаться с
харнесом с телефона в отдельной программке, а не в браузере.

## Как работает

- **Первый запуск** — приложение спрашивает адрес сервера. Можно сразу вставить
  полный адрес с токеном: `http://192.168.0.100:8321/?token=…`
  (поле автозаполняется из буфера обмена, если там похожий на адрес текст).
- Адрес запоминается. После первой успешной загрузки сервер обменивает токен на
  cookie, и приложение **сохраняет адрес уже без токена** — дальше открывается
  просто `http://192.168.0.100:8321`.
- Данные (cookie + localStorage веб-интерфейса) сохраняются между запусками.
- **Сменить адрес**: долгое нажатие на иконку → «Сменить адрес», либо кнопка
  «Сменить адрес» на экране ошибки.
- Back-кнопка — назад по истории WebView.
- **Обновить страницу / сменить адрес** — долгое нажатие на иконку приложения:
  там два шортката («Обновить», «Сменить адрес»); кнопка «Сменить адрес» есть
  и на экране ошибки. Pull-to-refresh намеренно не используется: веб-интерфейс
  харнеса скроллится внутри своих контейнеров, и жест перехватывал прокрутку.
- Скачивание файлов из GUI (deliverables) идёт через системный DownloadManager
  в папку «Загрузки».
- Внешние ссылки (другой домен) открываются в браузере; вложения из GUI —
  через системный выбор файлов.
- Настоящий edge-to-edge: системные панели прозрачные, WebView рисуется на весь
  экран — фон интерфейса (цвет или фотография) виден и за статус-баром, и за
  кнопками навигации. Отступ для контента внедряется внутрь самой страницы
  (чуть меньше высоты панелей), клавиатура сжимает страницу через тот же
  механизм. Контраст иконок подстраивается под светлоту фона автоматически.
- Экран ошибки с кнопками «Повторить» и «Сменить адрес».

Разрешён открытый HTTP (`usesCleartextTraffic="true"`) — адрес в локальной сети
без TLS. Для HTTPS-адресов это тоже работает без ограничений.

## Сборка

Всё собрано локально, инструменты в `toolcache\` (JDK 21, Gradle 8.9) и `sdk\`
(Android SDK, build-tools 34.0.0). Ключ подписи: `dsh-shell.keystore`
(пароль `dshshell2024`, alias `dshshell`) — **храните его**, с ним же
подписываются будущие обновления.

Пересборка вручную:

```powershell
$env:JAVA_HOME = 'C:\Deepseek-Harness\APK\toolcache\jdk-21.0.12.1+1'
$env:ANDROID_HOME = 'C:\Deepseek-Harness\APK\sdk'
$env:ANDROID_USER_HOME = 'C:\Deepseek-Harness\APK\android-user-home'
$env:GRADLE_USER_HOME = 'C:\Deepseek-Harness\APK\.gradle-home'
& 'C:\Deepseek-Harness\APK\toolcache\gradle-8.9\bin\gradle.bat' -p 'C:\Deepseek-Harness\APK' assembleRelease
```

Готовый APK: `app\build\outputs\apk\release\app-release.apk`.
